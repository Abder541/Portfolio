Administration VMware ESXi

Installation et configuration d'un hyperviseur VMware ESXi, puis déploiement et gestion de machines virtuelles Windows Server et Ubuntu.

📅 2024 ⏱ Projet école 🏫 Infrastructure & Virtualisation 👤 Rôle : Administration système
VMware ESXi Windows Server Ubuntu Virtualisation

Objectif

Installer et configurer un hyperviseur VMware ESXi sur un serveur physique, puis déployer et administrer plusieurs machines virtuelles (Windows Server, Ubuntu) dans un environnement de lab scolaire.

Contexte

Projet réalisé dans le cadre du CFC au Geneva Institute of Technology. L'objectif pédagogique était de maîtriser les bases de la virtualisation en entreprise : installation d'un hyperviseur bare-metal, création de VMs, configuration réseau et gestion des ressources.

Stack technique

ComposantTechnologie
HyperviseurVMware ESXi 7.x / 8.x
Client de gestionvSphere Client (Web)
VM 1Windows Server 2019 / 2022
VM 2Ubuntu Server 22.04 LTS
RéseauvSwitch, Port Groups, VLAN
StockageDatastore local (VMFS)

Ce que j'ai fait — étapes

  • Installation de VMware ESXi sur un serveur physique dédié (boot USB, configuration initiale)
  • Configuration réseau de l'hyperviseur : adressage IP statique, vSwitch, port groups
  • Création et installation d'une VM Windows Server (allocation CPU, RAM, disque, ISO)
  • Création et installation d'une VM Ubuntu Server (partitionnement, SSH, mises à jour)
  • Configuration des services de base sur chaque VM : AD DS sur Windows Server, serveur web (Apache) sur Ubuntu
  • Administration via vSphere Client : snapshots, monitoring des ressources, gestion des datastores
  • Tests de connectivité réseau entre les VMs et vers l'extérieur

Résultat / Livrables

  • Hyperviseur ESXi opérationnel avec deux VMs fonctionnelles
  • Windows Server configuré avec Active Directory Domain Services
  • Ubuntu Server avec serveur web Apache accessible depuis le réseau
  • Documentation technique du déploiement (procédure pas à pas)

Compétences démontrées

  • Installation et configuration d'un hyperviseur bare-metal (VMware ESXi)
  • Administration de machines virtuelles : création, snapshots, allocation de ressources
  • Configuration réseau virtuel : vSwitch, port groups, connectivité inter-VM
  • Administration Windows Server : installation, AD DS, gestion de base
  • Administration Linux : Ubuntu Server, SSH, Apache, mises à jour
  • Utilisation de vSphere Client pour le monitoring et la gestion

Leçons apprises

  • La virtualisation permet de simuler une infrastructure complète sur un seul serveur — idéal pour apprendre
  • La gestion des ressources (RAM, CPU) est critique : une mauvaise allocation dégrade toutes les VMs
  • Les snapshots sont essentiels pour expérimenter sans risque, mais ne remplacent pas une vraie stratégie de backup
