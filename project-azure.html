Projets Azure — Infrastructure Cloud

Déploiement de sites web et architectures sécurisées sur Microsoft Azure.

📅 2025 🏫 Projets école ☁️ Infrastructure Cloud
Azure VM MySQL Nginx PHP Bastion NSG Azure Files Cloud

Sous-projet A — Site Web dynamique connecté à Azure MySQL

  • Déployé une VM Ubuntu avec Nginx + PHP-FPM
  • Connecté à Azure Database for MySQL (Flexible Server) via SSL
  • Développé un dashboard PHP (CRUD) avec Bootstrap 5, Chart.js, protection CSRF
  • Configuré les NSG et règles de pare-feu MySQL

Sous-projet B — Architecture Bastion & VM privée

  • VM bastion (IP publique, SSH + RDP) comme seul point d'entrée
  • VM privée (aucune IP publique) accessible uniquement via le bastion
  • Partage Azure Files monté sur les deux VMs (SMB/CIFS + fstab)
  • Sous-réseaux séparés pour la segmentation réseau
  • Bureau à distance XRDP + XFCE

Stack technique
